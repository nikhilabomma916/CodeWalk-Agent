## 3. Defect Details

- Retest Result

## 4. Defect Status

The following statuses may be used:

- Open
- In Progress
- Fixed
- Retest Required
- Retested
- Closed
- Reopened
- Deferred

## 5. Severity

| Severity | Description |
|---|---|
| Critical | Issue prevents a major part of the system from functioning or causes a serious security/data problem. |
| High | Major functionality is affected and there is no suitable workaround. |
| Medium | Functionality is affected but the system can still be used with a workaround. |
| Low | Minor issue with limited impact on functionality or usability. |

## 6. Retesting

Defects marked as fixed will be retested using the related test case. The retest result and final defect status will be recorded in this document.
